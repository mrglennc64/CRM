# TrapRoyaltiesPro — Marketing Site UI Kit

A pixel-true recreation of the TrapRoyaltiesPro marketing site, built component-by-component using the design system's tokens.

## Components

- `Header.jsx` — fixed nav with logo, links, CTA
- `Hero.jsx` — headline + free scan form
- `Stats.jsx` — proof-points strip
- `HowItWorks.jsx` — 3-step process
- `Pricing.jsx` — 4-tier pricing grid + enterprise card
- `FAQ.jsx` — accordion (artist + publisher splits)
- `Footer.jsx` — links, legal, social
- `CTA.jsx` — banner with the guarantee
- `Button.jsx`, `Input.jsx`, `Card.jsx` — primitives

## Run

Open `index.html`. All components compose into a single landing page that demonstrates a complete user flow: scroll → enter Spotify link → submit → see a fake Submission Readiness Score.

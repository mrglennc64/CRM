Read the `README.md` file within this skill for the full brand context, then explore:

- `colors_and_type.css` — every design token (CSS vars). Import this in any HTML you generate.
- `assets/logo/` — wordmark and logomark SVGs (light + dark variants, plus a "clean catalog" verification seal).
- `assets/icons/` — note: this kit uses **Lucide** line icons via CDN (`https://unpkg.com/lucide-static@0.469.0/icons/<name>.svg`). Substitute by dropping local SVGs into `assets/icons/`.
- `preview/` — small reference cards for colors, type, spacing, components. Look here when you need to copy a swatch or a button style.
- `ui_kits/marketing/` — full marketing site recreation (Header, Hero, Pricing, FAQ, Footer). Lift components from `site.jsx`.
- `carousels/` — 12 Instagram carousels × 5 slides (60 total). All slides are 1080×1080. The shared layout system is in `carousel.css`; each deck is generated by JS in `index.html`. Use these as templates for new carousels — keep the same slide rhythm: hook → stat → reframe → fix → CTA.
- `content/captions.md` — captions, hashtags, and 12-week posting schedule.

## Voice rules (non-negotiable)

- Lead with money. Numbers first, mechanics second.
- "You," not "we." Address one artist or one rights manager.
- Plain English over jargon. Define ISRC/ISWC/IPI/CWR inline if used.
- Short, declarative sentences. Periods do work commas can't.
- No emoji in product UI. ⭐ tolerated as a single bullet glyph in marketing decks.
- CTAs are imperatives: "Get your free scan now."

## Color rules

- Five-color warm palette: `#D97706 amber`, `#F59E0B gold`, `#FDE68A soft yellow`, `#78350F deep brown`, `#1F2937 charcoal`. Plus `#FFFBEB cream` (use instead of white) and `#451A03 brown-900` (use instead of black).
- Never use pure white or pure black.
- Never use cool colors (blues, purples, cool grays).

## Type rules

- **Display/headlines:** Fraunces, 700–900, tight tracking (-0.02em).
- **Body/UI:** Inter, 400–600.
- **Mono/data:** JetBrains Mono — for ISRCs, ISWCs, hashes.
- All from Google Fonts. Substitute if commissioned faces are added to `fonts/`.

## When the user invokes this skill

If they don't say what they want, ask:
1. What surface? (Instagram carousel · landing page · pitch deck · ad creative · email)
2. Which audience? (Artists/creators — emotional · Publishers/rights teams — logical)
3. One core message? (Lead with the money figure or the pain point)

Then act as a brand-aligned designer: copy assets out of this skill into a new working folder, build the artifact in HTML, and surface it. Use the existing carousel JS template as a starting point if the ask is social.

If creating production code, you don't need to copy — link `colors_and_type.css` directly and import logos from `assets/logo/`.

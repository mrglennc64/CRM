# HeyRoya Design System

**Metadata Compliance for Nordic Publishers**

A professional service for validating splits, contributors, and registrations before submission to STIM, ICE, and rights organizations.

## Brand Positioning

- **Industry**: Music rights management & metadata validation
- **Audience**: B2B — Nordic music publishers, rights organizations (STIM, ICE), catalog managers
- **Tone**: Professional, precise, trustworthy — enterprise SaaS with music industry warmth
- **Value Proposition**: Metadata compliance for Nordic publishers. No integration. You stay in control.

## Core Principles

1. **Trust & Precision** — Data accuracy is critical; visual language should reinforce reliability
2. **Accessible Expertise** — Technical product made approachable for non-technical users
3. **Transparent Process** — Clear documentation, no black boxes, no automatic changes
4. **Music Industry Native** — Understands publisher workflows, speaks the language

## Design System Contents

- **Brand Assets** — Logo, wordmark, usage guidelines
- **Colors & Typography** — Tokens, scales, type system
- **Spacing & Shadows** — Layout primitives
- **Components** — Marketing site UI kit, product patterns
- **Templates** — Presentation decks, social assets

# HeyRoya Design System

Complete design system for metadata pre-validation platform serving music publishers and rights organizations.

## 📁 Structure

- **`tokens.css`** — Design tokens (colors, typography, spacing, shadows)
- **`Brand.html`** — Logo, wordmark, usage guidelines
- **`Colors.html`** — Color scales and semantic palettes
- **`Typography.html`** — Type system (Work Sans, Inter, JetBrains Mono)
- **`Spacing.html`** — Spacing scale, radii, shadows
- **`Components.html`** — Core UI patterns (buttons, cards, badges, inputs)
- **`Marketing-Site.html`** — Full marketing site UI kit
- **`assets/`** — Logo files (SVG)

## 🎨 Design Principles

1. **Trust & Precision** — Enterprise reliability with data accuracy focus
2. **Accessible Expertise** — Technical product made approachable
3. **Transparent Process** — Clear documentation, no black boxes
4. **Music Industry Native** — Speaks the language of publishers

## 🎯 Brand Essence

**Positioning**: Metadata Compliance for Nordic Publishers

**Tagline**: A professional service for validating splits, contributors, and registrations before submission to STIM, ICE, and rights organizations

**Audience**: Nordic music publishers, rights organizations (STIM, ICE), catalog managers

**Tone**: Professional, precise, trustworthy — enterprise SaaS with music industry warmth

## 🎨 Color Palette

- **Primary (Blue)**: Trust, data precision, enterprise reliability
- **Accent (Amber)**: Music industry warmth, approachability
- **Neutrals**: Cool-toned grays reinforce primary
- **Semantic**: Success (green), Warning (orange), Error (red)

## 📐 Typography

- **Display**: Work Sans — Headlines, hero text
- **Body**: Inter — UI text, descriptions
- **Mono**: JetBrains Mono — Identifiers, codes, technical data
